


📝 Forms — MUST KNOW

<form>
    <label>Name:</label>
    <input type="text">

    <label>Email:</label>
    <input type="email">

    <button type="submit">Submit</button>
</form>

| Tag          | Purpose             |
| ------------ | ------------------- |
| `<form>`     | Form                |
| `<label>`    | Input label         |
| `<input>`    | Input field         |
| `<textarea>` | Multi-line input    |
| `<button>`   | Button              |
| `<select>`   | Dropdown            |
| `<option>`   | Dropdown option     |
| `<optgroup>` | Option group        |
| `<datalist>` | Input suggestions   |
| `<fieldset>` | Group form controls |
| `<legend>`   | Fieldset title      |
| `<output>`   | Calculation/result  |
| `<progress>` | Progress indicator  |
| `<meter>`    | Measurement         |

🧠 Head / Metadata — IMPORTANT

<head>
    <meta charset="UTF-8">

    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">

    <title>My Website</title>

    <link rel="stylesheet" href="style.css">
</head>

| Tag       | Purpose           |
| --------- | ----------------- |
| `<meta>`  | Metadata          |
| `<link>`  | External resource |
| `<style>` | Internal CSS      |
| `<base>`  | Base URL          |
| `<title>` | Page title        |


🎨 CSS & JavaScript — MUST KNOW

CSS
<link rel="stylesheet" href="style.css">

or:
<style>
    h1 {
        color: red;
    }
</style>

JavaScript
<script src="script.js"></script>

| Tag          | Purpose                         |
| ------------ | ------------------------------- |
| `<link>`     | Connect external CSS/resources  |
| `<style>`    | Write CSS                       |
| `<script>`   | JavaScript                      |
| `<noscript>` | Content when JS isn't available |
